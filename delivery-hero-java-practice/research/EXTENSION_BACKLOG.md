# Optional extension references

These are **reference-only practice leads**, not extra runnable exercises. The core project contains 65 runnable exercises. This list avoids losing useful discoveries while keeping your first study route manageable.

## Secondary company-tag leads

The public list in [S22](SOURCES.md#s22) is unverified; do not treat its percentages or titles as confirmed interview frequency. Seven missing patterns were added to the main bank, while several others already existed. Remaining leads worth considering after the core:

| Lead | Pattern | When useful |
|---|---|---|
| [Maximum Beauty](https://leetcode.com/problems/maximum-beauty-of-an-array-after-applying-operation/) | Sorting / window | Extend P15 and P17 |
| [Group Shifted Strings](https://leetcode.com/problems/group-shifted-strings/) | Canonicalization | Extend P02 |
| [Climbing Stairs](https://leetcode.com/problems/climbing-stairs/) | Basic DP | Warm-up before P30 |
| [Bus Routes](https://leetcode.com/problems/bus-routes/) | BFS modelling | After P38 |
| [Word Pattern II](https://leetcode.com/problems/word-pattern-ii/) | Backtracking / bijection | After P02 and P31 |
| [Boundary of Binary Tree](https://leetcode.com/problems/boundary-of-binary-tree/) | Tree traversal | After P26 |
| [Valid Palindrome III](https://leetcode.com/problems/valid-palindrome-iii/) | Interval DP | Optional hard stretch |
| [Construct Quad Tree](https://leetcode.com/problems/construct-quad-tree/) | Divide and conquer | Optional spatial decomposition |

Basic numeric tasks and less transferable niche titles from that list are lower priority than demonstrating the core patterns under time pressure. Their omission from the runnable bank is deliberate prioritization, not evidence that they cannot occur.
