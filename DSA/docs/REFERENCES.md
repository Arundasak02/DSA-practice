# Selection references

The core is an authored practice sequence covering reusable patterns. It is not a frequency ranking or a list of verified questions from one employer.

- [Grind 75 rationale](https://www.techinterviewhandbook.org/grind75/faq): prioritize representative patterns and manageable difficulty before expanding the list.
- [NeetCode roadmap](https://neetcode.io/roadmap): a reference for progression through common algorithm topics.
- [Java 17 collections](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/package-summary.html) and [Streams](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/stream/package-summary.html): primary references for the Java tracks.

Historical interview evidence remains in the retained exercise comments, including its uncertainty labels. A public candidate report is anecdotal evidence; it does not establish current interview probability. Newly added D01–D20 are general fundamentals with locally authored contracts and tests. Tests define practice expectations, not an employer's hidden test suite.
